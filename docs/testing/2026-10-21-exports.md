# Windows 98 SE and ME audio export tables, 2026-10-21

Only function names and ordinals from export tables were inspected.
No Microsoft binary code, disassembly, sample or other binary contents
were inspected. No Microsoft binaries are checked in.

The source systems are this repository's pristine `vm/w98se.qcow2`
(98 SE with NUSB 3.3) and `vm/wme.qcow2` (ME). Existing offline raw copies
on E: were used, not live guest disks. 7-Zip extracted only the two named
system files to ignored `E:\usb-wdm-free\exports\98\` and `me\`.
MSVC 6.0 `DUMPBIN.EXE /exports` read their export tables. Output was
reduced to ordinal and name, omitting addresses, hints and summaries.

| System | Target-system file | Recorded table | Named exports |
|---|---|---|---:|
| 98 SE | `WINDOWS\SYSTEM32\DRIVERS\PORTCLS.SYS` | [w98port.txt](exports/w98port.txt) | 48 |
| 98 SE | `WINDOWS\SYSTEM32\DRIVERS\KS.SYS` | [w98ks.txt](exports/w98ks.txt) | 186 |
| ME | `WINDOWS\SYSTEM32\DRIVERS\PORTCLS.SYS` | [wmeport.txt](exports/wmeport.txt) | 57 |
| ME | `WINDOWS\SYSTEM32\DRIVERS\KS.SYS` | [wmeks.txt](exports/wmeks.txt) | 215 |

Both PortCls tables provide the current M0 imports:
`PcAddAdapterDevice`, `PcInitializeAdapterDriver`, `PcNewPort`,
`PcRegisterSubdevice` and `PcRegisterPhysicalConnection`. Both also
provide `PcNewServiceGroup`, `PcGetTimeInterval`,
`PcRegisterAdapterPowerManagement` and `PcForwardIrpSynchronous`.

`PcRegisterIoTimeout` is absent on 98 SE and present on ME (ordinal 48).
The shared oldest-target path therefore cannot statically import it.
NTKERN/VMM32 exports were not inspected in this run; NTOSKRNL import
availability and actual audio load/lifetime remain separate gates.
These are export-presence facts, not proof that a particular call or
driver works on either system.

## STREAM.SYS follow-up

For the synthetic webcam plumbing experiment, the same pristine offline
raw images supplied only `WINDOWS\SYSTEM32\DRIVERS\STREAM.SYS`, extracted
to ignored `E:\usb-wdm-free\exports\98stream\` and `mestream\`.
Again only export-table names and ordinals were read with `/exports`;
no binary code or other binary contents were inspected or checked in.

| System | Recorded table | Named exports |
|---|---|---:|
| 98 SE | [w98strm.txt](exports/w98strm.txt) | 20 |
| ME | [wmestrm.txt](exports/wmestrm.txt) | 22 |

Both provide `StreamClassRegisterAdapter`, `StreamClassDeviceNotification`,
`StreamClassStreamNotification`, `StreamClassScheduleTimer`,
`StreamClassQueryMasterClock` and `StreamClassQueryMasterClockSync`.
Their ordinals differ; source should import names. Presence does not prove
timer callback teardown, stream synchronization or camera functionality.
