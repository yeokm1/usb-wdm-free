are invented and the strict standard MIDI class parser is unchanged.

single-interface profile. It obtains the nine-byte configuration header,

02/81. The existing simulator path remains AC0/MS1. INF matching adds only
the exact Roland VID/PID whole-device identity, not a broad vendor match.
INF and original version resource are both 0.0.0.3. This has not yet run
in a guest or on physical Roland hardware; do not install merely on the
