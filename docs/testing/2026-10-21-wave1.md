## UAC2 host and build checks

```
src\audio\uac2\test.cmd
src\audio\uac2\build.cmd wdmx86 free
src\audio\uac2\build.cmd wdmx86 checked
src\audio\uac2\build.cmd wdm64 free
src\audio\uac2\build.cmd wdm64 checked
```

All pass with the kits in [toolchain.md](../toolchain.md). Host result:
3,557 assertions plus 1,143 single-byte mutations, using the saved X4
configuration. Every truncated input ends at a protected page boundary;
an over-read would fault the host test. The tests establish ten PCM
alternates, one skipped Type III alternate, explicit playback feedback
on `83`/`85`, capture on `81` marked implicit feedback, and terminal clock
paths `3 -> 34 -> 33`, `6 -> 38 -> 37`, `17 -> 36 -> 35`. Missing entities
and a selector cycle fail. Parsing is restricted to interfaces 3-6;
unrelated HID and CDC descriptors do not enter the audio model.

The portable parser performs no allocation or USB requests. A multi-input
selector needs the USB layer's one-based current selection; a one-input
selector can be walked directly. Clock multipliers currently fail their
path instead of assuming a ratio. Clock RANGE/CUR requests, endpoint
speed validation and implicit pairing remain to implement.

M0 `uac2wdm.sys` obtains the configuration from the lower USB stack,
parses the matching audio function and registers WaveCyclic and Topology
subdevices with one fixed 16-bit/stereo/48-kHz range. `NewStream` returns
not-supported. There is no timer pretending to play audio. This build
does not select configurations or alternates. It requires a function PDO
with a hardware ID containing `&MI_nn`. It now accepts the filtered
configuration returned by XP's USBCCGP, which omits the IAD and other
functions; the saved filtered fixture is separately tested. The pointer
walk to the lower device follows the design's
old-target path and still requires the M0 guest lifetime checks.

Both PE architectures pass their declared import gates and contain file
version `0.0.0.1`. Import-list membership is not export availability
evidence. `out/audio/uac2/<profile>/<flavour>/` holds commands, PE reports,
source/output hashes and `PASS.TXT`. The gate is a package-local copy of
the repository's smoke gate; it has no run-time/build dependency on the
smoke package. A shared build-script location remains a later cleanup.
The 2000 DDK's PortCls header includes `punknown.h` but this installed kit
names it `unknown.h`; a local include shim names the unmodified kit header.

## Mitsumi floppy and Windows 2000

`src/generic/usbprobe/usbdesc.py` confirms Full Speed UFI/CBI. Binary inputs,
hashes and capture conditions are in
`src/storage/usbflop/testdata/mitsumi/README.md`.

QEMU 11.1.0: a new overlay at
`E:\usb-wdm-free\wave1\w2kflop.qcow2`, backed by this repository's
`vm/w2k.qcow2`. Options: `-machine pc,acpi=off -cpu pentium3,-apic -m 256
-vga cirrus -rtc base=localtime -usb`, plus
`-device usb-host,vendorid=0x03ee,productid=0x6901`. Monitor:
`127.0.0.1:44332`. Test INF on a virtual FAT floppy at `A:\`.
The guest GUI was operated through QEMU's local monitor.

The [recorded Windows 2000 run](2026-10-21-usbflop-vm.md) confirms the
experimental parent and in-box floppy child start, no-medium behavior,
and idle removal. A new-port reattach chose Microsoft's specific entry.
The drive is already in Microsoft's VID/PID list, so automatic selection
is expected to retain Microsoft's line. Our CBI entry was manually
selected to exercise the Include/Needs path. No formatting or
media writes have been performed. A passthrough run here uses emulated
UHCI and cannot count as a physical EHCI test.
