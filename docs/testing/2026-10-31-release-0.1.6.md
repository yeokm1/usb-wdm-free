# Release 0.1.6: uac2 0.1.6.0, 2026-10-31

Owner, 2026-10-31: 0.1.5 plus `uac2` 0.1.6.0: the play position reported
to Windows is the fetch cursor, so a seek no longer replays a ring block
one lap old (design record 17, `1ab0dab`), and on Windows 2000 the
install asks for a restart (design record 18, `76b09bd`). Every other
file is 0.1.5's. [Release notes](../release-notes.md), section
"Release 0.1.6". The legs are in
[uac2-seek](2026-10-31-uac2-seek.md) and
[uac2-2000-stop](2026-10-31-uac2-2000-stop.md); this record is the
release operation.

## The build results

- `uac2` (`wdmx86 free`, `wdm64 free`): built at `9853c3c` (the version
  bump to 0.1.6.0 on `2b04b97`), clean, with `PASS.TXT`; both images
  read FileVersion 0.1.6.0. The release ran at `c533483`, and the
  release operation's freshness check found no source change between
  the two.
- The x64 `uac2wdm.sys`: the owner's signed copy of the `9853c3c` build
  (unsigned `5163efa1...`), in `E:\usb-wdm-free-wt\sign016b`. An earlier
  x64 image built at `2b04b97` still carried 0.1.5.0 and was set aside
  unused (`sign016-superseded`).
- Not rebuilt, because unchanged since `v0.1.5`: the co-installer
  `UACCI1.DLL` and `UACCI.INF` (x86 DLL and the INF from the tree, the
  x64 DLL as `strip:` entries) and `usbcom` (`USBCOM.SYS` and
  `USBCOMV.VXD` from the tree). A fresh link differs in the PE
  TimeDateStamp, which is inside the Authenticode digest (the 0.1.5
  release record), so 0.1.5's signed DLL is kept byte for byte.

## The release operation

`release\release.ps1 -Definition release\0.1.6.psd1 -X64Dir
E:\usb-wdm-free-wt\sign016b -Thumbprint
E6A2749B78E9E4074260CF79972A57EEB6E76C0A -Certificate
usb-wdm-free-test.cer -NonFree <usb-wdm-nonfree v1.1.0-2-g6a7243d>`.
`-X64Dir` holds each x64 image under the name of its `x64:` entry: the
owner's signed `uac2wdm.sys` copied as `uac2.wxp-x64.uac2wdm.sys` and
`uac2.wv-8-x64.uac2wdm.sys` (the signed file itself left as signed), and
the released x64 images of the tree for the `strip:` entries.

- Before the signature, `-Part x86 -Check`: "release: checks PASS";
  of the 75 x86 files only `uac2`'s three `uac2wdm.sys` and three
  `uac2wdm.inf` differed from the tree.
- `-Check`: "release: checks PASS; -Check, nothing published".
- The release: "release: PASS; free\, STAGE.TXT and SHA256.TXT written
  (101 files)", as 0.1.5.
- Every x64 image read signed by `E6A2749B...` (0.1.4's certificate), no
  timestamp, and matched its unsigned form outside the checksum and the
  certificate table: the `9853c3c` build for `uac2wdm.sys`, the released
  image with its signature removed for `UACCI1.DLL`, `rtl815x`,
  `usbmidi`, `xpad98` and `cdcnet`.
- Changed under `free/`: `uac2wdm.sys` and `uac2wdm.inf` in `uac2`'s five
  folders, nothing else. `STAGE.TXT` changes only in the notes of
  `uac2`'s five `uac2wdm.inf` lines; no STAGE or COPY systems changed.
