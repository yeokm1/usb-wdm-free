# boardids.txt - the USB ids the usbcom INFs list beyond the Uno R3 and the
# Pico (Owner, 2026-10-22: Leonardo/Micro and bootloaders, STM32 VCP,
# CH9102, Espressif 303A, Adafruit 239A, SparkFun 1B4F). The gates
# (validate.ps1, gate98.ps1) derive the expected INF model lines from this
# file. Only USB ids were taken from the sources below (facts, no code).
#
# Columns: VID:PID  kind  source  board
#   single    a single-function CDC device (bDeviceClass 02): listed as a
#             whole device on every system. For the Caterina bootloaders,
#             STM32 VCP and CH9102 this is an inference, read in M0/M2.
#   composite an Arduino-sketch PID (CDC plus other functions): whole
#             device on 98 SE/ME and 2000 only (owner Q5 exception), plus
#             &MI_00 for buses that split composites on 98; on XP and
#             later the interface-class match already serves it.
# Selection rules: Arduino AVR and SparkFun AVR list every PID of the named
# boards; PIDs with bit 15 clear (SparkFun: build.pid.0) are the Caterina
# bootloaders. arduino-esp32 and arduino-pico: pid.0 of every board whose
# vid.0 is 303A or 239A. Adafruit SAMD and nRF52: build.pid of every
# 239A board. A PID found in several sources is composite unless all say
# single. UF2 bootloader and CircuitPython PIDs are not listed.
